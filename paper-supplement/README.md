# Paper supplement

Scripts, result files and archived designs behind

> M. Laib, *Affine-geometry uniform designs: coincidence optimality,
> projection spectra and factor selection*, submitted to the Journal of
> Statistical Planning and Inference, August 2026 (earlier version:
> *Equidistant uniform designs from affine subspaces over GF(q)*, July 2026).

Every design is generated by `PGM2::Qn(m, n, p)`; versions 2.0.0 and 2.0.1
produce identical designs. Run each script from this directory with
`Rscript <name>.R`; each writes its result file next to it.

| Script | What it reproduces | Output | Time |
|---|---|---|---|
| `projection-spectrum.R` | Theorem 1: joint-table cell structure, contribution Phi, orthogonality criterion, Grassmann multiplicities M_r and the E(f_NOD) average, for the 13 configurations of Table 1 | `projection-spectrum-results.csv` | seconds |
| `partial-spreads.R` | Proposition 2 and Corollary 4 in PG(4,2), n = 2: partial spreads k = 2..5 (two-value bound, OA, E(f_NOD) = 0), exhaustive check on all 6545 three-column subsets, 50 random five-column subsets | `partial-spreads-results.csv` | seconds |
| `symmetric-cd2.R` | Table 1 (Section 5): centred L2-discrepancy of the family and of 20 optimised random comparators per configuration, identical optimiser and budget; also random LHD reference values | `symmetric-cd2-results.csv`, `optimized-designs/*.rds` | ~15 min |
| `extensions.R` | Table 2: E(f_NOD) margins and DD^2 excess of the comparators over the family's closed forms; the catalogue (Table 3) | `enod-ddexc-results.csv`, `catalogue.csv` | minutes |
| `benchmark.R` | Package timings quoted in the R Journal article | `benchmark-results.csv`, `benchmark-session.txt` | minutes |

`levelperm-results.csv` is an earlier level-permutation run kept for the
record; Table 1 uses `symmetric-cd2-results.csv`.

All random draws derive from a single master seed, so every file is
exactly reproducible. The `optimized-designs/` directory holds, for every
configuration, the construction and optimised designs with their per-factor
level permutations and, for each comparator, the initial and optimised
designs, permutations, scores and seeds.
